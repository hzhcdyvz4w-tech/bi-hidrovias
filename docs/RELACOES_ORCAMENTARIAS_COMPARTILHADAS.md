# Relações orçamentárias compartilhadas

## Finalidade

Permitir que um empreendimento sem orçamento próprio individualizado apresente, no Relatório Executivo, o orçamento de uma ação/PO relacionada **sem tratá-lo como valor exclusivo** e sem duplicá-lo nos totais consolidados.

## Regra de filtros

A relação só é ativada se o alvo e a fonte pertencem ao mesmo recorte dos filtros principais até a categoria **Tipo**:

Região → UF → Município/Abrangência → Hidrovia/Rio → Tipo.

A seleção do empreendimento define qual item será exibido no relatório.

## Relação inicial

- Alvo: Supervisão das 54 IP4
- Fonte orçamentária: Operação e manutenção de 54 IP4
- SIOP: Ação 20LN / PO 0002 / GND 3
- PLOA 2027: 20LN / localizador 0001 - Nacional
- Natureza: compartilhado / não exclusivo

Quando os dois empreendimentos estão simultaneamente no recorte, a relação compartilhada não é adicionada aos totais SIOP, evitando dupla contagem.
