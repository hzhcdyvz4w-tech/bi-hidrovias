# Janela Orçamentária — anexo SEI compartilhado

A Janela Orçamentária passou a reutilizar diretamente a mesma base local do módulo Processos SEI.

- **Anexar ZIP do SEI** abre o mesmo seletor de arquivos do importador SEI.
- **Abrir Processos SEI** leva ao módulo de importação e auditoria.
- Os pacotes novos são gravados no mesmo IndexedDB `BI_Hidrovias_SEI`.
- A Janela Orçamentária atualiza a análise quando os contadores da Base SEI mudam.
- Nenhum documento SEI é enviado ao GitHub.
